RakshakAI

AI-Assisted Disaster Intelligence & Response Platform

RakshakAI is a web-based disaster intelligence command center designed to help analyze potential disaster scenarios using environmental signals, geographic context, disaster type and estimated population data.

Live Demo: https://rakshak-ai-lovat.vercel.app

---

Problem

During a disaster, decision-makers need to quickly understand:

- What type of disaster is occurring?
- Where is it occurring?
- How severe could the impact be?
- How many people could be affected?
- What actions or resources may be required?

RakshakAI explores how an AI-assisted interface can bring these inputs together into a single operational dashboard.

---

Features

- Disaster-management command-center interface
- Environmental monitoring dashboard
- Seismic activity, wind speed, water-level and temperature indicators
- Indian state/location input
- Disaster-type selection
- Estimated population input
- Predictive incident-analysis workflow
- Live intelligence and action-directory sections
- Responsive web interface

---

Tech Stack

- Frontend: Next.js, React, TypeScript
- Styling: CSS / project styling system
- Deployment: Vercel
- Development: Git, GitHub
- AI-assisted development: Used AI tools during implementation and iteration

---

How It Works

1. The user selects or enters the relevant disaster parameters.
2. The application combines the location, disaster type and estimated population with available environmental information.
3. The analysis workflow processes the scenario.
4. The interface presents the resulting intelligence to help the user understand the potential situation and appropriate response actions.
